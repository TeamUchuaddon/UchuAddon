# UchuAddon

**UchuAddon** は、**Nebula on the Ship** 向けに作られたアドオンです。  
新しい役職やゲーム要素を追加し、プレイ体験を拡張します。

## UchuAddonの利用ガイドライン
UchuAddon(以下「本アドオン」と呼称します)の利用については、以下のガイドラインを遵守してください。
なお、Mod、アドオン、その他一切の制作物を以下「MOD」と呼称します。
また、本アドオンを、Nebula on the Shipのマーケットプレイス、又はGitHub上の本アドオンのリポジトリからダウンロードし、インストールしてプレイすることは、自由に行っていただけます。
但し、ダウンロードまたは利用した時点で、当ガイドラインに同意したものとみなします。

1. 役職アイデア及び仕様について
本アドオンのオリジナル役職(モディファイヤを含む。以下同じ。)及びオリジナル機能を他MODに移植していただくことは可能ですが、その際は以下の条件が適用されます。
  - 移植先のMODの配布ページ・README等の、利用者が確認できる場所に、本アドオンの名称(UchuAddon)、本アドオンをTeamUchuAddonが制作した旨、本アドオンのGitHubのリンク(https://github.com/TeamUchuaddon/UchuAddon) 並びに本アドオンから移植したオリジナル役職及びオリジナル機能の名称を、クレジットとして記載する必要があります。
  - 移植先のMODに移植した本アドオンのオリジナル役職及びオリジナル機能には、移植後も本ガイドラインが適用されます。移植先のMODの制作者は、上記のクレジットと併せて、移植した部分に本ガイドラインが適用される旨を記載する必要があります。また、移植先のMODから更に他MODへ移植する場合も、本ガイドラインに従う必要があります。
  - 本アドオンのオリジナル役職及びパークについては、それぞれの総数の30%以上に当たる数を他MODへ移植することはできません。また、本アドオンから移植した役職数が移植先のMODの移植後の役職数の過半数となる場合も移植することはできません。
  - 移植先のMODのオリジナル役職数が役職数全体の30%未満である場合、移植先のMODに本アドオンのオリジナル役職やパーク、その他一切の機能を移植し、又は本アドオンの一切の資産を利用することはできません。
  - その他、本アドオンに重大な悪影響を及ぼし、公序良俗に反し、又は意図的に本ガイドラインの制限を回避していると判断した場合、TeamUchuAddonは移植等の許可を取り消す権利を留保します。

　ただし、上記の規定にかかわらず、本アドオンのオリジナル役職をNebula on the Shipのアドオンに移植することは禁止します(役職以外のオリジナル機能等は移植していただいても構いませんが、トラブル防止のため出典元の記載を必須とします)。

【注意】
他MOD由来の役職については本項は適用されません。詳細は「4. 他MOD由来の役職等について」をご確認ください。

3. 独自リソースの利用禁止
アドオン内に含まれる以下のリソースの自作発言、及びそのまま(あるいは改変して)抜き出し他MODやプロジェクトへ移植・利用することは一切禁止します。
